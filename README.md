# 🍽️ Zomato Restaurant Data Analysis

## 📌 Project Overview

This project analyzes the Zomato Restaurant Dataset using Python. The objective is to explore restaurant trends, customer preferences, online ordering patterns, ratings, and votes through data analysis and visualization.

---

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

---

## 📂 Dataset

Zomato Restaurant Dataset (CSV)

---

## 📊 Analysis Performed

- Data Cleaning
- Missing Value Handling
- Restaurant Type Analysis
- Online Order Analysis
- Rating Analysis
- Votes Analysis
- Heatmap Visualization
- Countplots
- Histograms
- Line Charts

---

## 📈 Visualizations

- Restaurant Type Distribution
- Votes by Restaurant Type
- Online Order Analysis
- Heatmap
- Rating Distribution

---

## 🔍 Key Insights

- Delivery restaurants receive a large number of customer votes.
- Online ordering is preferred by many restaurants.
- Restaurant type significantly influences customer engagement.
- Heatmap shows the relationship between restaurant type and online ordering.
